**Multitask Transformer Models for Demographic and Industry Profiling on Long-Form Blog Texts**

**Transactions on Machine Learning Research**.

This work includes:
- Preprocessing and cleaning of the **Blog Authorship Corpus** (670K samples)
- Training and fine-tuning multiple models (BERT, DeBERTa, BART-CNN, etc.)
- Running **25+ experiments** with different transformer architectures
- Performance evaluation, error analysis, ablation studies, and embedding analysis (UMAP, confusion matrix)
