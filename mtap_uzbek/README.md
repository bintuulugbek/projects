Our paper has been accepted to the **International Conference on Electrical, Computer, Communications and Optimization (ICECCO 2026)**.

This work contributes to the field of Uzbek text classification, focusing on articles extracted from **kun.uz** and trained using the Uzbek multilingual transformer model **BertBek**. Our study provides a systematic evaluation of **multi-task learning for Uzbek news classification**, along with an annotated dataset and empirical insights for future low-resource NLP research.

In this research, I :
- Collected and processed articles from kun.uz using web scraping
- Trained and fine-tuned transformer models, including BertBek
- Conducted performance evaluation, error analysis, and ablation studies
